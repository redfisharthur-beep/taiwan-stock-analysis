## v0.16 本次調整：上市／上櫃／ETF

- 已從 `public/index.html` **直接移除「新手先看這裡：3 個數字怎麼理解？」整個區塊及框線**，並清理 `public/style.css` 中對應的已廢棄樣式。
- 觀察卡片左側市場欄位僅顯示「上市」或「上櫃」；ETF 位於獨立群組中，卡片同樣標示其上市／上櫃市場；價格僅在右側顯示一次，ETF 報價不假設幣別都是新台幣。
- 後端取消每日觀察原先的 500 元上限、加入最新官方 ETF 報價（含字母後綴代碼，拒絕將權證及 ETN 當 ETF），上市與上櫃各自獨立形成觀察名單。兩個市場最新資料日期不同時，不會悄悄刪掉較晚更新的市場整組股票。
- `/api/search` 支援正式上市、上櫃公司及可由官方當日行情辨識的 ETF 名稱／代碼。`/api/analyze` 對 ETF 提供**單獨的基金行情、成交量、K 線和可取得的技術指標**；ETF 不適用發行公司的 EPS、負債比或公司本益比，不產生不具財務意義的 100 分公司綜合評分。
- 官方行情初篩跨越所有已辨認的上市／上櫃股票與 ETF；首頁每組最多五檔，**不是將每檔都完成九份歷史財報／籌碼研究**。個股深入查詢依 FinMind/授權來源的實際回應進行，沒有資料不自動補零。
- **範圍限制：** 當前母體是證交所上市股票、櫃買中心上櫃股票和兩市場可辨認 ETF；興櫃股票、ETN、權證、未上市投資商品、ETF 持股／淨值／折溢價／費用率尚未建立完整對應來源，不能冒充已完成全台所有投資商品。ETF 若未出現在該日官方批次行情，也不能以推測報價補入當日名單。
- **排程資料庫可選**：已綁定 D1 才執行持久化全市場掃描和逐檔歷史分析；ETF 另儲存基金價量與技術資料，不把 ETF 當一般公司填入營收／財報／EPS。沒有 D1 時，上市、上櫃及 ETF 官方觀察仍可即時使用。

## 已完成的原始碼功能

- `src/providers.js`：證交所／櫃買中心公司名冊、官方行情與 ETF 分類、官方估值，全市場初篩；保存可辨認的產業分類。公司名冊中無當日成交價的公司仍留在母體，不以舊價冒充有效收盤價。
- `src/fundamentals.js`：同一報告期毛利率、營業利益率、淨利率、簡化季度 ROE、流動比率、負債比、營收年增率與營業現金流。財報來源缺欄位、不具可比較期間時輸出 null，不能虛構分數。個股頁保留原始詳細分析及更新日期。
- `src/industry.js`：**不必設定 D1**，可直接以現有 TWSE／TPEx 名冊及官方當日估值批次資料，計算同市場、同產業、同日估值的本益比／淨值比／殖利率 PR。需要全市場各檔財報、籌碼及歷史技術 PR 時，仍要先取得各檔相同期間的真實數據；若產業或樣本不足則顯示待查。
- `src/market-db.js` + `migrations/0001_market.sql`：可啟用 D1 市場資料庫，記錄全部上市櫃公司名冊及日行情、估值、每檔不同季度的原始公開財報資料集、近 130 筆日價、完整已評分的技術及籌碼研究結果、獨立來源日期及失敗狀態。不得以 null 充當 0 分。
- `src/worker.js`：每個交易日的官方全市場資料排程更新、每五分鐘逐檔限量取得 FinMind 公司財報／歷史價／法人／融資資料或 ETF 歷史行情、每週同步 TDCC 集保資料；透過 D1 任務欄位分批接續，不在一次免費 Worker 請求中全市場同時連續發 API。網站讀取已入庫行情時直接出名單；無 D1 時保留原先官方資料即時查詢模式。個股頁 `/api/analyze?stock=2330` 增加基本面細項及可取得的同產業 PR。
- `/api/market-status`：回傳公司數量、財報已入庫數、技術已取得數、籌碼條件已齊數和最近更新時間；`/api/health` 顯示 `marketDBConfigured`。這些數量代表確實儲存的檔數，不代表每檔的所有項目已齊或當日皆已更新。

## 本次資料缺漏與介面清理

`public/index.html` 和 `public/app.js` 已直接移除使用者指定的長段提示及「尚待完成」彙總；需要核對的資料仍保留在各個指標細項及「資料來源與更新說明」，不以刪除文字假裝資料已經存在。成功的官方／FinMind 同日價格驗證不再顯示冗長綠色提示；若價格不一致，仍顯示必要的異常警示。

- **獲利品質／負債**：對齊真正同報告期的現金流與稅前淨利，接受 FinMind 常見總資產／總負債同義類別，保留負債已知但現金流比率缺值的真實數字。必須兩者皆可比才計入完整 10 分；金融類企業另需產業專用模型。
- **法人近五日**：以最新五個連續、已正式公布的交易日統計真實買賣超／成交股數；最多容許最新收盤資料超前兩個交易日，缺日不補零。
- **400 張以上持股三週**：個股分析在當週 TDCC 開放資料不足三週時，嘗試透過公開的 [TDCC 第三方每週原始資料備份](https://github.com/wirelessr/tdcc-opendata-archive) 核實三期不同日期、同公司、四個級距的真實紀錄；失敗或過期仍標記未評。第三方備份並非官方即時 API，資料來源會明確標註。排程入庫另有每週持股快照紀錄，**不需要 D1 才能使用公開備份檢查單一個股**。
- **重大公告與事件**：上市及上櫃 MOPS 官方公告若有真實公司代號、日期與主旨，可先得到 2／5 的官方資料驗證分；獨立媒體同事件核實後才按獨立報導規則評估，不會把沒有新聞當作正面消息。
- **獨立新聞及產業事件**：需已授權、可核對的原始新聞來源。既有 `NEWS_FEED_URL`＋`NEWS_FEED_TOKEN` 可接受同個股新聞；產業事件額外要求兩家不同原始媒體對同一 `industryEventId`，每篇需帶 `stock`、`eventType:"industry_event"`、`title`、`publishedAt`、`publisher`、`originalPublisher`、`url`，且兩篇發稿日相距不超過三天。未配置授權來源、原文不符或無實際產業事件時，不產生獨立新聞／產業事件分數。

**程式與單元測試已具備上述驗證機制，不代表網站當下每檔股票皆有這六項資料。** 仍需正確部署、可用的 FinMind 資料、MOPS、集保三週來源和授權獨立新聞；不會為提高涵蓋率補造公告、籌碼、產業事件或 100 分總分。

## 選用：持久化全市場歷史資料才需要配置儲存層

**現有官方 API＋FinMind＋永豐後端已能即時分析個股，不需 D1。官方同日估值資料亦可不經 D1 直接作同業 PR。** D1 是儲存全市場逐檔、多季財報及歷史技術、籌碼分析的可選實作，非資料來源或分析引擎；也能沿用現有 Render 服務搭配資料庫與批次分析結果，再提供 Cloudflare 唯讀查詢。若選擇本專案的 D1 實作：GitHub 原始碼、資料表 migration 和 Cron 已提交，但**無法從只有 GitHub 連線的工作環境，替你的 Cloudflare 帳號建立資料庫、取得資料庫 ID 或替你部署 migration**。目前尚未核實 D1 已綁定／資料已填入，不能宣稱全市場財報、籌碼、技術都已完成。請在已連線 Cloudflare 帳戶的本地 terminal 或 Cloudflare 可用的 CLI 環境按順序執行：

```bash
npm install
npx wrangler d1 create taiwan-stock-market
```

將上一步輸出的實際 `database_id` 填進現有 `wrangler.jsonc` 頂層（與 `triggers` 同層）的 `d1_databases` 配置；不要把假 ID 或 D1 API Token 推到 GitHub。

```json
"d1_databases": [
  {
    "binding": "MARKET_DB",
    "database_name": "taiwan-stock-market",
    "database_id": "貼入 Cloudflare 回傳的實際資料庫 ID",
    "migrations_dir": "migrations"
  }
]
```

接著執行：

```bash
npx wrangler d1 migrations apply taiwan-stock-market --remote
npx wrangler deploy
```

在 Cloudflare Worker Secrets 確認 `FINMIND_TOKEN` 仍有效；永豐 `SJ_API_KEY`／`SJ_SEC_KEY` 只放在既有 Render 服務，不放前端或 GitHub。瀏覽 `/api/health` 應顯示 `version:"0.15.0"` 和 `marketDBConfigured:true`；瀏覽 `/api/market-status` 查目前已儲存檔數及更新時間。D1 若尚未初始化則市場同步入庫功能不會啟動，公開網站仍使用現有官方資料＋FinMind 即時分析，也會盡可能顯示官方同業估值 PR。

已配置的 Cron（UTC）：

- `0 11 * * MON-FRI`：交易日台北時間 19:00 以官方名冊與最新行情建立市場快照；官方市場資料未齊時保留前一份資料庫快照。
- `*/5 * * * *`：逐次選取一檔資料庫中的公司，抓取九項 FinMind 資料集及技術、籌碼來源，保存多期財報與近期歷史價格。資料失敗記錄錯誤並在之後重試；不可超出 FinMind 授權流量、Cloudflare D1 配額或延遲要求。
- `30 11 * * FRI`：台北時間週五 19:30 嘗試讀取 TDCC 週股權分散資料並保存每檔有效股權分散與三週趨勢。

**完整母體入庫與各檔資料補齊不是同一件事。** 建立資料庫後應持續核對 `/api/market-status` 中的 `total/finance/technical/chips` 差距。停牌、停止交易、財報尚未公告、FinMind 授權或額度不足、資料來源格式改變、金融業特殊會計口徑時，個股財務／技術／籌碼可能仍為待查；不得標示為全市場 100% 完成。現行排程為避免公開行情被個人券商資料再散布，不會對全市場輪詢或輸出私人永豐行情。Cron、資料表 migration 及靜態測試通過也**不等於**已完成 Cloudflare 線上部署或首次完整回填。

## 評分與簡明顯示（2026-09-24）

- 基本面 40 分、技術面 30 分、籌碼面 30 分，合計 100 分。已核實重大消息另外加減分，不占基本面／技術面／籌碼面的涵蓋權重；無可核實事件為 0 分。負面事件可扣分，最後綜合分數限制在 0～100 分。
- 基本面、技術面、籌碼面的指標卡片僅呈現中文指標、數值與一句短解；不在卡片重複 FinMind 名稱、資料日期、指標計算口徑或較長的來源備註。資料來源與核對結果保留在獨立折疊區及 API 中。
- 「資料涵蓋」僅計入真實可評分的基本面、技術面、籌碼面分數上限，**只有確實取得 100/100 分涵蓋時才輸出綜合分數**；缺漏不自動補 0、不以消息取代缺漏。任何來源暫未公布或上游缺值時，無法保證每檔股票即時達成 100% 資料涵蓋。
